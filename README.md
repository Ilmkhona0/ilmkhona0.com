# ilmkhona0.com

This repository contains the Next.js website copied from the AWS-hosted source repository and configured for Vercel. The AWS source repository remains separate.

## Run locally

```bash
npm ci
npm run dev
```

Open <http://localhost:3000>.

## Deploy on Vercel

Connect this repository to a Vercel project and use the detected Next.js defaults. Add the environment variables described in [VERCEL-SETUP.md](./VERCEL-SETUP.md) before relying on database, authentication, email, AI, or upload features.
